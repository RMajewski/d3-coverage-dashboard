# README Description

D3 Coverage Dashboard is a visual tool built with D3.js and TypeScript that parses and displays test coverage data based on V8 coverage reports. It offers a clear overview of feature files, test scenarios, and executed steps, with collapsible details for individual test cases. Additionally, it highlights which source files were merely invoked (e.g., during setup) versus those that were actively tested. The project uses pnpm, is powered by Vite for development, and employs semantic-release for automated versioning and changelog generation.
